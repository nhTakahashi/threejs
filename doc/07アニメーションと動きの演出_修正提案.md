# Session 07: アニメーションと動きの演出 修正提案

対象: `07アニメーションと動きの演出.pptx`

現在のサンプルは `three@0.184.0` を使用している。この版では `THREE.Clock` が非推奨になっており、実行時に警告が出る。教材の「delta time を使う」という考え方は維持したまま、コード例を `THREE.Timer` に更新する。

## 必須修正

### スライド 8: `Clock` を `Timer` に置き換える

見出しを「`Timer` - 時間を基準にする」に変更する。`Timer` は値を読む前に、各フレームで `update()` を一度呼ぶ必要がある。

```js
const timer = new THREE.Timer()
timer.connect(document)

function animate(timestamp) {
  requestAnimationFrame(animate)

  timer.update(timestamp)
  const delta = timer.getDelta()
  mesh.rotation.y += 1.2 * delta
  mixer.update(delta)

  renderer.render(scene, camera)
}

animate()
```

本文中の API 名も次のように変更する。

- `clock.getDelta()` -> `timer.getDelta()`
- `clock.getElapsedTime()` -> `timer.getElapsed()`
- 描画を停止する実装では `timer.dispose()` でイベントリスナーを解除する。

### スライド 13: 周期運動の例を更新する

`getElapsedTime()` は `Timer` には存在しないため、次の形に差し替える。

```js
timer.update(timestamp)
const time = timer.getElapsed()
mesh.position.y = Math.sin(time * 2) * 0.5
mesh.rotation.y = time * 0.4
light.position.x = Math.cos(time) * 3
```

### スライド 14: 最小コードの時間処理を更新する

`Clock` を `Timer` に変更し、`timer.update(timestamp)` を `getDelta()` の前に追加する。タイムスタンプを `requestAnimationFrame` のコールバック引数から渡すことも明記する。

```js
const timer = new THREE.Timer()
timer.connect(document)

function loop(timestamp) {
  requestAnimationFrame(loop)
  timer.update(timestamp)
  mixer.update(timer.getDelta())
  renderer.render(scene, camera)
}

loop()
```

## 追記を推奨する点

### スライド 7: アニメーションクリップなしの GLB を考慮する

すべての GLB にアニメーションが含まれるわけではない。`gltf.animations[0]` を無条件に再生せず、空配列を確認する例にする。

```js
if (gltf.animations.length > 0) {
  const mixer = new THREE.AnimationMixer(gltf.scene)
  mixer.clipAction(gltf.animations[0]).play()
}
```

### スライド 16: クロスフェード前に次のアクションを初期化する

複数クリップがあることを確認し、切替先を `reset()` してから再生すると、前回の再生位置を引き継がず安定する。

```js
if (clips.length >= 2) {
  const idle = mixer.clipAction(clips[0])
  const walk = mixer.clipAction(clips[1])
  idle.play()

  walk.reset().play()
  idle.crossFadeTo(walk, 0.5, true)
}
```

### スライド 19: フェードインには透過設定が必要

GLB のマテリアルをフェードさせる前に `transparent = true` を設定する。メッシュが複数あるモデルでは、すべてのマテリアルを対象にする。別モデルとマテリアルを共有する可能性がある場合は、先に `material.clone()` する。

```js
model.traverse((child) => {
  if (!child.isMesh) return

  child.material = Array.isArray(child.material)
    ? child.material.map((material) => material.clone())
    : child.material.clone()

  const materials = Array.isArray(child.material)
    ? child.material
    : [child.material]

  materials.forEach((material) => {
    material.transparent = true
    material.opacity = 0
    gsap.to(material, { opacity: 1, duration: 0.8, ease: 'power2.out' })
  })
})
```

`timeline.progress()` を `opacity` に代入する書き方は、フェード用トゥイーンがタイムラインより先に終了すると不透明度が `1` に到達しないため、教材例には使用しない。

### スライド 19: カメラ演出では `OrbitControls` の target も扱う

`OrbitControls` を有効にしたままカメラ位置だけを動かす場合、注視点との組み合わせを確認する。モデルへ寄る・引く演出では、必要に応じて `controls.target` も同じタイムラインで補間し、毎フレーム `controls.update()` を呼ぶ。

## 修正不要の内容

- `AnimationMixer`、delta time、イージング、GSAP タイムライン、`sin` / `cos` の説明は現行版でも有効。
- GSAP の導入コマンド `npm install gsap` は現在のサンプル構成と一致している。
